# Security Policy
## Reporting Security Issues
If you notice any security issue or unexpected behavior in this project, please avoid reporting it through public GitHub issues.
Instead, kindly contact the project maintainer so the issue can be reviewed and fixed responsibly. Since this is an academic project, responses may take some time, but all reports will be taken seriously.
## Project Scope
This project is developed as part of an academic and learning-based initiative focused on machine learning and Wi-Fi CSI data analysis.
It does not involve real-time user interaction, authentication systems, or sensitive personal data. All datasets used in this project are static and stored locally for research and experimentation purposes only.
## Dependency and Code Safety
The project uses common open-source Python libraries for data processing and model training. To ensure better stability and reduce unexpected issues, dependency versions are pinned in the `requirements.txt` file.
No API keys, passwords, or confidential credentials are hardcoded in the source code. Users are encouraged to review the code and run it in a controlled local environment.
